# Grafight

数学関数・微分方程式の軌道で敵を撃ち合う砲撃ゲームです。
HTML / CSS / Vanilla JavaScript (HTML5 Canvas) のみで実装されており、ライブラリ依存なしでブラウザ上で動作します。

🎮 **[今すぐブラウザで遊ぶ (GitHub Pages)](https://kokincho.github.io/grafight/)**

---

## 主な特徴・機能

### 1. 4つの関数入力モード
- **$y = f(x)$（通常モード）**: 入力した関数のグラフがそのまま弾道になります。自軍兵士の位置を通るよう、自動的に $y$ 軸方向にオフセットされます（オフセット値は入力欄横にリアルタイム表示）。
- **$y' = f(x, y)$（1階微分方程式）**: ルンゲ・クッタ法で方程式を数値積分し、その解曲線が弾道になります。
- **$y'' = f(x, y, y')$（2階微分方程式）**: 兵士の初期位置に加え、**発射角度**（$\uparrow \downarrow$ キーまたはボタンで調整）を初期条件として軌道を解きます。
- **$r = f(\theta)$（極座標）**: 盤面中央を極とする極座標グリッドで、弾は $\theta$ が増える向き（反時計回り）に進みます。兵士の位置の角度 $\theta_0 \in [0, 2\pi)$ から始まり、兵士を通るよう自動的に $r$ 方向へオフセットされます。変数は `θ`（`theta`, `t` も可）。

### 2. 柔軟なゲームモード
- **同一端末対戦**:
  - **ターン制**: 制限時間つき（5秒〜180秒 / 無制限）で交互に射撃。
  - **リアルタイム制**: 両プレイヤーが同時に数式を入力して撃ち合います（兵士ごとのクールダウン制）。
- **キャンペーンモード**:
  - 初心者向けのチュートリアルから難関ステージまで、全12ステージを収録（Stage 9〜12 は極座標ステージ）。進捗はブラウザに自動保存されます。

### 3. 多彩なカスタマイズ・便利機能
- **弾の貫通設定**:
  - なし（通常）：障害物・兵士に命中すると爆発
  - 兵士を貫通：敵・味方を貫通して突き抜ける
  - 障害物を貫通：黒い障害物をすり抜ける
  - すべて貫通：画面端まで軌道を描き切る
- **兵士ごとの関数・角度記憶**: 選択した兵士ごとに以前入力した数式や角度が保持されます。
- **軌道プレビュー機能**: 発射前に破線で弾道を確認可能（オプション）。
- **一時中断・名前付きセーブ**: メニュー画面からいつでもゲームを保存・再開可能。

## ローカルでの実行方法

静的ファイルのみのため、任意のHTTPサーバーで実行できます：

```bash
# リポジトリをクローン
git clone git@github.com:KokinCho/grafight.git
cd grafight

# Pythonでローカルサーバーを起動
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。
